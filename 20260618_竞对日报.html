6月17日凌晨，智谱AI在海外正式上线并开源GLM-5.2，Hugging Face同步上线权重、全系国产芯片Day 0适配、本地可立即部署。这是6月13日面向GLM Coding Plan付费用户提前开放API后的"完整开源"动作。模型采用744B MoE混合专家架构+MIT宽松协议（免费商用、无地域限制），1M（100万Token）上下文——比上代GLM-4.6的200K提升5倍，依赖HiSparse稀疏注意力+KV8量化+IndexShare4优化，百万长度下信息遗忘大幅下降。官方Demo显示可一次性载入88万Token完整项目代码，全仓库代码重构/百万字合同/多阶段Agent工程任务均能"从头看到尾"。

Code Arena盲测拿下全球可用模型第一的成绩；FrontierSWE大型软件工程评测仅落后Claude Opus 4.8约1%-4%，是当前排名最高的开源模型；Design Arena审美评测全球第一；推理计算量比传统注意力降低66%，长文本调用成本仅为海外闭源旗舰的1/6。双档思考模式（High/Max）让开发者按需切换速度与深度——日常用High、干硬活上Max。完整自主工程链路可让单条需求自动完成"需求拆解→编码→联调→测试→打包"全流程，几小时内交付一个网页/手机/小程序都能用的完整应用。

算力基础设施层面同样关键。GLM-5.2的线上推理依托多个国产算力平台，Day 0完成与华为昇腾、平头哥、摩尔线程、寒武纪、昆仑芯、沐曦、燧原、海光、壁仞等国产算力平台的推理适配——意味着政企客户在国产芯片集群上即可实现高吞吐、低延迟、大并发的稳定运行，本地私有化部署零合规断供风险。这一节奏精准踩中6月12日Anthropic Fable 5/Mythos 5被美国出口管制封禁的窗口期，"前沿智能不应只属于少数人，也不应被少数规则随时收回"的官方表述明确了"国产替代"的市场卡位。

资本侧同一天传来关键信号。6月17日下午，证监会网站显示智谱科创板IPO辅导状态正式变更为"辅导验收"，辅导券商为国泰海通证券——意味着公司已完成股份制改造、合规治理、财务规范等上市前核心筹备工作，距离正式向上交所递交招股申报材料仅一步之遥。同日陆家嘴论坛上，证监会主席吴清宣布扩大科创板第五套标准适用范围至人工智能领域，上交所同步发布《大模型企业适用科创板第五套上市标准审核指引十五条》明确阶段性成果为"至少一个大模型产品已完成上线发布并实现规模化应用"。智谱港股1月8日上市时首发市值超510亿港元、上市43天累计涨幅超500%、市值一度突破3200亿港元，6月1日董事会通过科创板上市议案、拟发行股份占发行后总股本2%-8%、募资约150亿元（120亿投基座大模型+20亿投MaaS平台+10亿补流）。2025年全年营收7.24亿元同比增长131.9%，MaaS平台ARR达17亿元（一年内提升60倍）；经调整净亏损31.8亿元（2024年24.6亿元）；综合毛利率41%——本地化部署业务占总营收73.7%、毛利率显著高于云端业务；客户续约率达95%。

AI产品侧重磅加码。阿里云宣布将于今年下半年面向马来西亚和欧洲市场推出一整套Agentic AI产品矩阵，包括：一站式智能体开发与构建平台AgentRun、综合智能运维平台STAROps、提供硬件级安全隔离并降低智能体运营成本的ACS Agent Sandbox、面向智能体的一体化防御平台Agent Security Center、AI Security Guardrails 2.0以及AI智能体驱动的企业级安全运营平台Agentic SOC。这套"六件套"从开发、运维、安全、防御四个维度完整覆盖Agentic AI全生命周期，是阿里云首次系统性对外展示"Agentic AI Infra"框架。

数据与模型层同步推进。面向数据开发与数据库管理场景，阿里云DataWorks Data Agent与一系列AI原生数据库服务率先在日本、马来西亚和欧洲市场同步上线——DataWorks Data Agent可将自然语言意图直接转化为生产级数据开发任务，把传统数仓开发交付周期从"数天级"压缩至"数分钟级"；AI原生数据库服务覆盖Data Agent for Analytics（分析洞察）、Meta（数据资产与知识管理）、DAS（数据库运维）、DataBridge（数据采集）等多款产品。模型层，阿里云百炼国际版同步在日本上线，面向当地企业与开发者开放千问旗舰模型Qwen3.7-Plus并支持调用第三方大模型；视频生成模型HappyHorse与多模态模型Qwen3.5-Omni也将通过百炼国际版为日本客户提供企业级在线推理服务。

海外客户案例持续落地：数字金融领域，马来西亚领先的数字钱包TNG eWallet运营商TNG Digital基于阿里云统一数据平台升级搜索与推荐能力；本地化大模型领域，YTL集团旗下YTL AI Labs联合阿里云推出马来语ILMU模型家族，已落地Ryt AI、ILMUchat、ILMU Claw及ILMU API Platform等多款应用；AI内容创意领域，Morphyx.io与Tabspace.ai通过百炼国际版接入万相2.7、HappyHorse等视频生成模型及千问大模型；企业管理与跨国协同领域，阿里巴巴与SAP合作正从中国市场向东南亚、中东、非洲扩展，RISE with SAP、SAP AI Core及SAP BDC三大产品将于2026年内上线阿里云平台，千问大模型正在集成至SAP AI Core。后续阿里云还将在荷兰、巴西新设地域节点、进一步扩建韩国、迪拜等地数据中心。

6月17日，"豆包每天收入不足百万"冲上微博热搜。晚点LatePost独家报道引爆全网——截至今年上半年，豆包每日使用用户超2亿人，但每日收入不足百万元，主要来自电商佣金；到今年5月，豆包应用每天消耗算力达数千万（参照火山引擎公开API价格、结合豆包大模型毛利率、用户使用习惯推算）。文字聊天按每天人均15-20分钟使用时长只要几分钱，但推理、图片识别、语音/视频聊天等多模态功能所需算力成本要贵几倍甚至几十倍。AI产品榜最新数据显示豆包5月MAU为3.3亿、环比下降1.81%、约607万用户流失——尽管仍以近1亿的优势领先第二名阿里千问（MAU 2.34亿），但用户规模出现首次收缩。

字节已开始调整AI资源分配，重心从豆包这类面向大众的产品转向服务企业的产品。两个月前有字节高层到访Anthropic（其Claude Code 2025年5月上线，半年做到10亿美元年化收入，今年2月翻到25亿），回国后字节便参照Anthropic范式（用AI编程让巨额基建投入产生回报）调整AI资源分配。Seedance已证明企业服务方向可行：年化收入（ARR）已达20亿美元（约143亿元），单月超10亿元——几乎抵消豆包的算力成本；Seedance毛利率达70%（每卖出10元API调用，服务器和推理成本约占3元），但绝大多数收入来自企业客户且收入增速近期已有所放缓。
