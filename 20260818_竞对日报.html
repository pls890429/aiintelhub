阿里云Qwen-Audio-3.0系列语音模型正式上线：ASR/TTS/实时交互三项全球第一，千问与百炼双平台开放
来源：IT之家 / 阿里云官方公众号 / Artificial Analysis · 2026-08-17

8月17日下午，阿里云通过官方公众号宣布Qwen-Audio-3.0系列语音模型正式上线千问AI平台和阿里云百炼平台，开发者可通过API调用或订阅Token Plan使用。该系列包含三款模型：语音识别大模型Qwen-Audio-3.0-ASR、语音合成大模型Qwen-Audio-3.0-TTS、实时语音交互对话模型Qwen-Audio-3.0-Realtime。

在全球权威AI评测平台Artificial Analysis今年7月的语音排行榜上，该系列斩获语音识别（ASR）、实时交互（RealTime）和语音合成（TTS）三个赛道的全球第一，拿下"大满贯"。其中ASR模型支持复杂语境和专业领域识别；TTS模型支持多语种、多方言，可控制情绪、语气与节奏，提供0.6B和1.7B两种轻量版本，最低4G显存即可本地部署，端到端合成延迟低至97毫秒；Realtime模型支持端到端语音理解与对话，可边听边说、随时打断追问，并支持工具调用。目前该系列已在千问App、千问办公、Qoder等产品中应用。

⚡ 竞争影响：阿里云在语音AI赛道完成从识别、合成到实时交互的全栈布局，三项全球第一的背书直接对标火山引擎Seed-Audio和腾讯云语音服务。对浙江制造业客户而言，Qwen-Audio-3.0的低延迟和多方言能力在智能客服、工业质检语音记录、车载交互等场景具备落地价值，且轻量版本可边缘部署。

钉钉全球商业总裁杨猛离任加入蚂蚁集团：距6月组织调整不足两月，副总裁任卿接手商业化全链路
来源：21世纪经济报道 / 野马财经 / 亿欧 · 2026-08-17

8月17日，据21世纪经济报道从接近钉钉的知情人士处获悉，钉钉全球商业总裁、客户发展部负责人杨猛已完成离职相关内部流程，计划加入蚂蚁集团。钉钉悟空副总裁任卿（花名"易统"）将接手杨猛负责的商业化工作，涵盖直销、电销、服务商、售前、交付、客户成功全链路。此次离任由杨猛主动提出，距钉钉新CEO陈宇森6月18日发布组织调整全员信、成立客户发展部交由杨猛负责，尚不足两个月。

杨猛2002年加入阿里（工号598），是"中供铁军"成员，2019年调任钉钉负责销售，后升任全球商业总裁。在其任职期间，钉钉ARR从2023年超1亿美元增长至2025财年上半年超2亿美元。接任者任卿是钉钉老将，曾任硬件负责人、开放平台与商业化总经理，2021年随陈航（无招）离开创办两氢一氧，2025年阿里收购后回归，此前主要负责DingTalk A1等AI硬件业务。当前钉钉累计用户超8亿，接入数千万企业组织，3月发布AI原生工作平台"悟空"，7月整合QoderWork、悟空、MuleRun推出"千问办公"并于8月3日公测，14日上线GLM-5.3与DeepSeek V4 Pro。

⚡ 竞争影响：钉钉商业化一号位在AI转型关键期换人，反映阿里对企业服务AI商业化增速的更高预期。任卿接手后首要挑战是协调钉钉、悟空/千问办公、阿里云三方的客户归属与收入确认关系，这可能短期内影响大客户决策节奏。对华为云而言，钉钉-千问办公-阿里云的产品矩阵整合尚在磨合期，是争夺浙江大中型企业协同办公与AI Agent市场的时间窗口。

腾讯云与CPE源峰签署战略合作备忘录：1500亿AUM资管数字化生态，覆盖AI算力/产业赋能/微信生态
来源：观点网 / 网经社 / 新浪财经 · 2026-08-17（8月14日签约）

8月14日，CPE源峰与腾讯云在深圳签署战略合作备忘录，腾讯集团高级执行副总裁、云与智慧产业事业群CEO汤道生见证签约。双方围绕数字基础设施、产业AI赋能、微信生态与数字营销、行业标杆场景共创四个领域展开深度合作，腾讯云将作为首选战略伙伴协助CPE源峰及其被投企业数字化升级。CPE源峰核心团队累计投资超300家企业，资产管理规模逾1500亿元，签约现场汉堡王中国、卫龙食品、赤坎古镇、雍禾植发等13家被投企业代表参会。

在数字基础设施方面，双方将围绕AI算力、绿色数据中心、区域节点拓展及海外基础设施布局探讨合作；在产业AI方面，将结合腾讯混元大模型、TCADP智能体平台及WorkBuddy、CodeBuddy等产品，面向消费、医疗、文旅等赛道探索组织级AI生产力方案；在微信生态方面，依托企业微信、小程序、视频号、腾讯会议等工具，在广告投放、私域运营、品牌增长等方向合作。这是腾讯云"投资生态+云服务"绑定模式的又一落地案例——通过PE机构的被投企业网络批量触达行业客户。

火山引擎
火山引擎豆包"工作任务"模式新增手机远程控制电脑：手机端下达指令、PC端自动执行，进度实时回传
来源：时代周报 / 快科技 · 2026-08-17

8月17日，豆包发布产品更新，"工作任务"模式新增手机远程控制电脑功能。同一账号授权后，用户在手机端下达任务指令，已连接的电脑端可读取本地文件、操作软件完成执行，进度和结果实时回传手机。该功能覆盖通勤、离开工位、出差等移动场景，用户无需守在电脑前即可调度PC完成文档处理、数据整理、软件操作等任务。

同期，火山引擎豆包搜索B端开发者文档显示，8月豆包搜索针对Global版本与Custom版本完成多项功能迭代：Global版本新增文搜图能力，新增IcpHostOnly入参可将搜索范围限定在ICP备案网站之内，新增AuthorityLevel字段标识搜索结果来源网站的权威等级；Custom版本推出更高规格的畅享版订阅套餐，完成MCP工具多协议支持扩展，并对权威搜索AuthInfoLevel进行优化。豆包搜索开放服务于7月28日推出，目前国内9成头部手机厂商智能助手已接入，覆盖办公AI、金融投研、商业分析、电商内容创作等场景。

腾讯云
腾讯混元Hy3宣布国际市场扩展：WorkBuddy全球免费至8月底，TokenHub与OpenRouter同步开放API
来源：Medcom / Tencent Cloud International · 2026-08-17

8月17日，腾讯正式宣布混元大模型（国际版名称Hy3）扩大国际市场访问范围，全球用户和企业可通过AI原生工作台WorkBuddy免费使用其高级推理能力，免费期至太平洋时间8月31日。同时，创意工作室Tencent Design Miora和腾讯云TokenHub模型管理平台也提供免费接入，开发者可通过API将Hy3直接集成到应用和内部开发工具中。

技术层面，Hy3采用混合专家（MoE）架构，总参数2950亿，结合快速与深度混合思考机制，API调用量较上一代模型增长超68倍。在Tencent Design Miora中，Hy3能够编排多个专业AI Agent，将自然语言指令转化为图形、视频、3D对象和UI等创意资产。Hy3 API同时通过OpenRouter向全球开发者开放。这是腾讯云继7月WorkBuddy国内上线后，在海外市场加速AI产品商业化的重要一步，与阿里云Qwen系列在Hugging Face上的国际推广形成直接竞争。

独立研究员测试发现Kimi K3/GLM-5.2存在海外顶级模型蒸馏痕迹：DeepSeek凭纯强化学习路线检测"干净"
来源：讲古科技 / 独立安全研究员Alexander Panfilov团队 · 2026-08-17

独立安全研究员Alexander Panfilov团队近期发布一组测试结果：将顶级模型Claude Opus 4.8的加密思维链提取不到总Token量1%的片段，预填进不同模型的推理开头，Kimi K3的整套推理风格立刻发生漂移，部分测试案例几乎复刻Opus的表达习惯，从Kimi K3中提取顶级模型推理片段的难度比基线模型低100万倍；GLM-5.2也测出类似记忆痕迹。唯独DeepSeek的测试曲线与从未见过这些内容的空白模型基本重合。

研究团队通过小模型Haiku 4.5逐字解密Opus原始思维链后，对多个热门模型进行"基因比对"。DeepSeek之所以"干净"，源于其从R1代起走纯强化学习路线——R1论文明确训练数据截止2024年7月（早于o1发布），未设专门蒸馏环节，R1-Zero靠GRPO框架独立训练，512张H800 GPU训练80小时、总成本29.4万美元。这一测试在行业引发热议：走快速迭代路线的Kimi和GLM性能追得快但存在"指纹"争议，走纯RL路线的DeepSeek训练难度更高但独立性更强。国产模型与海外顶尖模型的性能差距已缩小至2.7%（斯坦福2026 AI指数报告），OpenRouter上中国模型周Token调用量达36.11万亿，是海外模型的5倍。
