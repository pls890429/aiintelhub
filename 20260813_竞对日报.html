腾讯Q2营收首破2000亿创历史：AI投入致自由现金流首次转负-138亿，云收入同比+20%，刘炽平称算力出租可获30%+利润
2026-08-12 · 21世纪经济报道/36kr/东方财富/腾讯财报 | ✅ 已验证

8月12日港股盘后，腾讯发布2026年Q2财报。营收2048亿元（+11%），首次单季突破2000亿；Non-IFRS经营利润756亿元（+9%），剔除新AI产品影响后861亿元（+19%）——两者差距105亿元，即AI新产品（Hy/元宝/CodeBuddy/WorkBuddy/小微）本季经营亏损约105亿元，高于一季度的88亿元。IFRS净利润560亿元（+0.7%）低于市场预期584亿元，主要因一家非上市投资公司可转换优先股重估产生100亿元非现金亏损。

AI投入规模空前。资本开支528亿元（+176%），上半年累计847亿已超2025年全年792亿；研发开支273亿元（+35%）；技术基础设施运营成本同比翻倍至152亿元，折旧支出+46%至112亿元。高额投入致自由现金流首次转负（-138亿），剔除算力采购预付款后为376亿元。截至6月底现金净额从一季度末1469亿降至582亿。营销服务收入436亿元（+22%）为增速最快板块，AI广告推荐模型和AIM+智能投放产品持续优化。

刘炽平在电话会上表示，算力投入已看到明显回报上行空间，此前下达的部分算力订单售出可获30%以上利润。他提出"先自建模型、再开发应用、最后对外出租"的三步走策略，称将打造极具规模的原生AI业务。财报披露Hy3持续位列OpenRouter全球前三，Hy4计划近期上线将提升多模态能力；WorkBuddy用户增长和付费意愿强烈，月访问量2097万位列国内企业AI代理第一；微信AI智能体"小微"已启动小范围灰度测试，由专注隐私和微信场景的定制化模型WeLM驱动。金融科技及企业服务收入603亿元（+9%），其中云收入同比+20%。

⚡ 浙江影响：腾讯云收入+20%且AI需求驱动明显，浙江企业在腾讯云上的AI算力采购议价空间可能改善；刘炽平"算力出租30%+利润"表态意味着腾讯云有动力对外出租闲置算力，浙江企业可关注GPU租赁优惠窗口；自由现金流首次转负提示腾讯下半年可能进一步收紧低毛利集成项目，浙江政企客户需关注腾讯云在总包项目上的参与意愿变化；Hy4即将上线和微信"小微"灰度测试值得关注，WorkBuddy付费意愿强烈说明企业AI办公产品已进入商业化验证期

DeepSeek V4 Pro正式版深夜悄然上线：1M上下文+384K输出，多项Agent测试逼近全球前沿模型，价格暂未上调但涨价预告仍在
2026-08-13 · 钱江晚报/新浪科技/CSDN | ✅ 已验证

8月12日深夜，DeepSeek官网API文档悄然更新，模型版本从V4-Pro预览版切换至DeepSeek-V4-Pro-0813正式版。V4 Pro正式版支持1M上下文窗口、最高384K输出，支持thinking/非thinking模式（默认开启thinking），同时支持JSON Output、Tool Calls、Responses API、Anthropic API兼容及FIM补全（Beta），并发限制500。官方尚未同步发布更新日志，更新日志页面最新一条仍是7月31日的V4-Flash正式版更新。

多家科技媒体援引DeepSeek官方群流出的评测对比表称，V4-Pro-0813在多项智能体测试中已逼近Anthropic前沿模型Claude Fable 5，部分项目甚至超越Fable 5，相比V4 Pro预览版整体表现明显提升。由于这些分数来自官方群及社区而非正式发布，仍属非官方披露数据。DeepSeek在7月31日发布V4-Flash正式版时已披露智能体能力大幅增强：Terminal Bench 2.1达82.7、NL2Repo达54.2、DeepSWE达54.4、Toolathlon verified达70.3，并明确表示正式版智能体能力远超V4-Pro-Preview。

价格方面，V4 Pro正式版暂未上调：缓存命中输入0.025元/百万Token、缓存未命中输入3元、输出6元。相比V4-Flash（输入1元/输出2元），Pro版输出价格贵三倍，定位高端场景。但官网仍保留涨价预告——"计划近期整体上调DeepSeek API服务的定价，预计涨幅较大"。此次"能力升级、价格暂不变"更像涨价前的性能升级和产品切换。V4 Pro正式版上线几乎与Grok 4.6发布同步，两款主打高性价比的模型同时冲击前沿模型第一梯队。V4系列结构进一步清晰：Flash（1元/2元/并发2500）主打高频低成本，Pro（3元/6元/并发500）面向超长上下文和复杂Agent任务。

⚡ 浙江影响：V4 Pro正式版（1M上下文+384K输出）适合长文档分析和复杂Agent任务，浙江企业可按需选用——日常客服/FAQ继续用V4-Flash（1元/2元）控制成本，长代码库分析和多步骤Agent任务切换V4 Pro（3元/6元）；涨价预告仍在，建议在正式涨价前完成关键业务场景验证和Token额度储备；V4 Pro并发限制仅500（Flash为2500），高频调用场景需评估并发瓶颈；多项Agent测试逼近全球前沿模型意味着国产模型在Agent场景已具备替代海外旗舰的能力

火山引擎
火山引擎发布行业首个综合Agent套餐"Agent Plan"：整合豆包+GLM+Kimi多模型与工具链，引入AFP计费和四档订阅
2026-08-12 · ai-damn/火山引擎官方文档 | ✅ 已验证

8月12日，火山引擎推出行业首个综合Agent套餐"Agent Plan"（方舟Agent计划），标志着从"模型API调用"向"模型+工具链一体化交付"的范式转移。套餐整合字节自研模型（豆包Seed、Seedance、Seedream）与第三方模型（GLM-5.1、Kimi-K2.6），并引入"Model and Harness"（模型+工具编排）方案，搭配网页搜索、视觉处理等实用工具。火山引擎方面表示"正在超越模型战争，不再是谁的模型最大，而是谁能创建在真实业务环境中实际可用的完整解决方案"。

套餐引入"AFP"（Agent Fuel Value/Agent燃料值）透明计费单位，提供四档订阅选项（基础版到Max版），Medium及以上订阅者可免费使用云端ArkClaw工具。ArkClaw是火山引擎基于开源OpenClaw框架打造的云端Agent SaaS，提供7×24小时在线实例、飞书原生集成、多模型切换和ClawHub 10000+技能。ArkClaw企业版已支持Agent Plan的购买、席位管理、模型配置和Skill调用，提供沙箱环境、共享Claw实例、MCP应用集成、专业数据库（A股行情/工商风险/宏观指标）等企业级能力。

ArkClaw Coding Plan订阅从Lite版59元/月到标准版118元/月起，活动首月50-99元。企业版支持自定义镜像管理、私有网应用访问、Webhook外部接入、云电脑（CUA）操作录制生成提示词等高级功能。此次Agent Plan的推出是字节AI商业化的重要一步——火山引擎MaaS今年目标营收150亿元，豆包Token日消耗量180万亿，企业客户超100万。通过将多模型+工具链打包为标准化套餐，火山引擎试图从"卖模型API"升级为"卖Agent解决方案"，降低企业Agent开发门槛。

⚡ 浙江影响：浙江企业构建AI Agent时可评估Agent Plan套餐——整合豆包+GLM+Kimi多模型+工具链的打包方案可降低多模型管理和工具集成复杂度，AFP计费提供透明用量管控；飞书重度用户优先体验ArkClaw云端Agent（Lite版59元/月起），飞书原生集成在办公场景中体验领先；企业版的沙箱环境、专业数据库和云电脑能力适合浙江金融/制造企业的数据安全需求；建议与DeepSeek Agent Harness、智谱ZCode做三方对比选型
阿里云
阿里千问开放平台正式上线+AI Arena发布：首批接入顺丰/自如/美的等十余家企业，覆盖手机/PC/AI眼镜三端，从问答助手升级为服务生态
2026-08-10/12 · 新快报/钛媒体/财新/千问AI平台 | ✅ 已验证

8月10日，阿里旗下千问开放平台正式上线，面向生态伙伴和开发者开放手机、PC和AI眼镜三类终端的AI智能体接入能力。首批接入伙伴覆盖物流运输、房产居住、本地生活、理财、汽车等十余个领域，包括顺丰速运、自如租房、盈米基金、哈啰租车、闪送、飞常准、美的美居等企业，菜鸟、夸克网盘等阿里生态产品同步接入。用户在千问App中"@"相关服务即可进入智能体对话空间，完成从咨询、推荐到下单的完整服务链路，如顺丰智能体可记住用户寄送地址直接完成寄件需求。

8月12日，千问AI平台又上线"千问AI Arena"——面向AI Agent的挑战与评测平台，从真实业务中持续产生挑战任务。首发任务聚焦跨境电商商品上架，要求Agent一次生成面向美国、韩国和巴西三市场的多语言商品文案及主图、详情图、商品视频，设金奖1名（等值1万美元Token）、银奖2名、铜奖2名，优秀方案可成为阿里云AI生态合作伙伴并在2026云栖大会展示。机器评测+专家盲审结合，8月中旬启动机器评测，8月31日进入专家评审。

过去一周阿里在AI领域密集布局：8月3日发布Qwen3.8-Max（2.4万亿参数），8月7日千问上线办公助理/定时任务/智能体广场等功能，8月10日开放平台上线并推出专业会员分三档收费（19-128元/月），8月12日AI Arena发布。华泰证券研报指出基础模型竞争正由产品探索走向高价值场景与企业市场商业化。QuestMobile数据显示千问月活1.67亿排第二，但仅为第一名豆包（3.82亿）的44%，千问正通过"模型+办公助理+开放平台+AI Arena"组合加速追赶。影石Insta360 GO Ultra已接入千问大模型，千问还将作为AI能力集成至国行Apple智能。

⚡ 浙江影响：浙江生活服务类企业（物流/租房/家政/出行）可评估接入千问开放平台——用户在千问App内直接调用服务完成下单，AI入口流量红利正处于早期；浙江制造企业可关注千问AI Arena跨境电商任务挑战，优秀方案可获商业化落地路径；千问将集成至国行Apple智能覆盖iOS/iPadOS/macOS/visionOS，浙江App开发者需关注Apple智能+千问的集成接口；千问办公助理专业会员（19元/月起）与WorkBuddy、豆包企业版形成三方竞争，浙江企业可从"与现有办公系统兼容度"维度选型

智谱ZCode用户突破100万：四项新功能上线，GLM-5.2+ZCode任务通过率超海外主流Coding工具2.39%，FrontierSWE评测开源模型首次逼近闭源前沿
2026-08-11/12 · 证券日报/llm-stats.com | ✅ 已验证

8月11日，智谱宣布其AI编程产品ZCode用户数突破100万，同步上线Goal（目标规划）、Subagents（子智能体）、Remote Control（远程控制）及闲时任务四项新功能，推动Coding Agent从对话辅助走向复杂任务自主交付。ZCode是针对GLM深度优化的国产Coding Harness，智谱自研Z.ai Code Bench显示GLM-5.2搭配ZCode后任务整体通过率较搭配Claude Code提高2.39%，优势集中在需跨文件、跨环节协作并完成最终验收的复杂任务。ZCode通过缓存命中率优化将GLM Coding Plan有效额度提升约30%，叠加8月31日前1.5倍额度活动，整体使用量接近翻倍。

智谱正加快构建"基础模型+Coding Harness+订阅服务"的AI编程生态，与DeepSeek Agent Harness部门、字节ArkClaw形成三方竞争。ZCode的快速发展依托GLM-5.2模型能力——744B总参数/40B激活、MoE架构、1M上下文、MIT授权免费商用，API定价输入1.40美元/输出4.40美元/百万Token（缓存命中0.26美元）。

与此同时，最新FrontierSWE评测（面向数小时级工程项目的软件工程基准）显示，GLM-5.2以74.4%的得分排名全球第四，与Anthropic闭源旗舰Opus 4.8（75.1%）仅差0.7个百分点——这是开源模型在前沿级软件工程任务上首次逼近闭源顶级水平。榜单前三为Claude Fable 5（90.0%）、Kimi K3 max（81.2%）、Opus 4.8（75.1%），Qwen3.8-Max以73.5%排名第五。FrontierSWE测试AI Agent能否完成需数小时的开放式技术项目，涵盖系统优化、大规模代码构建和应用级ML研究，标志着AI编程评测从"修Bug"升级到"做工程"。不过该榜单大部分分数为厂商自报，第三方独立验证极少。

⚡ 浙江影响：GLM-5.2在FrontierSWE评测中74.4%仅落后Opus 4.8 0.7个百分点，MIT免费商用的开源模型在数小时级工程项目中已达生产可用水平，浙江金融/医疗/政务等数据安全要求高的行业可评估GLM-5.2私有化部署替代海外闭源模型；ZCode用户破百万验证了国产Coding Harness的实用性，浙江软件企业可试用GLM Coding Plan评估ZCode在跨文件复杂任务中的表现，缓存优化+1.5倍额度活动可降低试错成本；FrontierSWE榜单分数多为厂商自报，选型时建议自行验证
