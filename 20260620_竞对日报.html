6月20日07:00，全球科技圈围绕"中国AI何时追平Anthropic顶级Fable系列"爆发公开辩论。马斯克在X平台公开表态"国内大模型至少要等到2027年一季度才能追平Anthropic顶级Fable系列"，这一保守预判被智谱AI首席科学家唐杰直接下场回怼——态度鲜明、底气十足，迅速引爆全网热议并吸引硅谷顶级投资人主动转发。这场跨国AI大佬交锋的焦点是6月17日智谱正式开源的GLM-5.2——一款在Artificial Analysis综合榜单上取得51分、Code Arena全球可用模型盲测第一的744B MoE旗舰。1M上下文+双思考模式（High/Max）+MIT协议+Day 0全栈国产算力适配，被业内视为"国产开源模型最接近改写规则的一次发布"。

支撑唐杰"硬刚"底气的是GLM-5.2的实打实技术实力。在权威编程评测中，GLM-5.2的FrontierSWE得分仅比Claude顶级版本低1个百分点、综合性能反超GPT-5.5，跻身全球第一梯队。SWE-Marathon超长周期软件工程测试虽仍落后Opus 4.8约13%，但FrontierSWE/SWE-Multilingual/Terminal-Bench 2.1/MCP-Atlas等多项长程任务基准全部介于Claude Opus 4.7与4.8之间，是排名最高的开源模型。88万tokens完整项目代码可一次性加载+Moonshot实验中用Rust从零重建阿波罗11号制导计算机（65000行飞控程序原样起飞）+复杂系统工程与深度调试稳定性大幅提升，构成"长程任务能力的实操证据链"。

资本侧的关键节点是6月22日（星期一）的股东会。香港联交所公告显示，智谱将于6月22日下午二时在北京市海淀区中关村东路1号院9号楼10层图灵会议室召开2025年年度股东会，议程包括：审议2025年度董事会工作报告/利润分配方案/续聘毕马威会计师事务所/2026年度股份激励计划等普通决议案，以及两项特别决议案——建议A股发行并在科创板上市（发行股份占发行后总股本2%-8%，即9,098,838-38,768,964股，募资总额约150亿元）+建议变更本公司英文名称为"Z.AI Co., Ltd."（原名Knowledge Atlas Technology Joint Stock Company Limited）。

DeepSeek识图模式全量上线+"认不出梁文锋"全网热议：网页端无门槛开放+App同步更新，多模态补齐与第一梯队最后一环差距

6月18日下午，国产大模型DeepSeek正式全量开放识图模式，网页端无门槛使用，手机App同步更新上线——持续两个月灰度测试的图像理解能力终于面向所有用户开放。这是DeepSeek V4（4月24日发布）以来多模态能力的标志性补齐：今年4月底开启小范围灰度、5月扩容测试、6月18日网页端100%开放、App端标注内测标识。内置快速模式、专家深度思考、识图三大切换入口，支持单图、多图批量上传，官方宣传覆盖试卷解题、表格数据分析、实物识别、网页截图文字提取四大核心场景。DeepSeek多模态研究员陈小康6月18日在X平台发文证实："Vision现已在网页端和App端上线。"

全网热议的"名场面"是创始人识别翻车。21世纪经济报道记者6月19日实测：上传DeepSeek创始人梁文锋的公开采访照片，系统反复识别出错——先后误判为寒武纪创始人陈天石、董宇辉、雷军、王兴、马化腾、杨植麟等公众人物，甚至在几分钟深度推理后直接坦言"我无法准确判断图中人物姓名，随意猜测容易产生误导，不建议给出不确定答案"。同一张照片上传至豆包、元宝和千问后，均能正确识别。Kimi创始人杨植麟、智谱创始人唐杰的照片同样无法正确识别，但对公众知名度较高的小米创始人雷军，DeepSeek则能准确给出答案。这一翻车折射出DeepSeek训练数据"小众人物素材不足+无内部人脸定向优化+不支持联网检索"三重客观限制，并非产品缺陷。

实际办公场景的可用性测试则给出更积极的结论。表格/财报图表识别——上传Excel截图、柱状图、折线图，自动提取全部数值、计算同比/环比变化、输出完整分析总结，多层复杂图表逻辑也能梳理清晰，速度控制在20秒以内；试卷/手写计算题——中小学数理化题目、高数公式实拍，自动分步演算、标注解题步骤、手写潦草字迹也能完成识别；城市建筑/日常物品实拍——街景、水果、家电实拍识别准确率接近100%，能补充材质、型号、背景科普信息；代码与UI处理——代码报错截图/UI界面解析、结合上下文给出修复方案甚至反向生成可交互HTML代码，按钮跳转等交互细节都能复原。这意味着开发者拍个代码截图就能直接询问优化建议。

当前局限：训练数据截止于2025年5月左右，识别较新产品或时事容易出错；缺少联网检索功能，冷门人物/新晋热点识别准确率不高；精细识别能力有短板——能识别出汽车但无法识别具体品牌、能识别出是人但无法分析具体是谁；高并发时段偶有解析失败情况。人物识别薄弱恰反映DeepSeek未使用大量未经授权的人脸数据进行训练，隐私保护角度反而值得肯定。能力边界意义大于产品缺陷——多模态已成为头部大模型产品的标配，ChatGPT/Gemini/豆包/腾讯元宝/阿里千问均已支持图像理解，字节Seedance/快手可灵进一步拓展至视频生成；DeepSeek此前长期以文本推理为核心、此次识图功能上线意味着其能力边界正从文本推理向多模态延伸，补齐与第一梯队最后一环差距。

6月19日0点（北京时间），腾讯云数据库AI服务DatabaseClaw正式开启商业化计费，标志着腾讯云数据库+AI战略在4月15日推出DatabaseClaw后两个月的商业化节点落地。计费策略采用体验版（免费）与企业版（付费）双轨并行模式——体验版面向中小企业和开发者零成本体验AI数据库运维核心能力，企业版面向有SLA保障/合规审计/生产级部署需求的大型客户按量付费。商业化时点与腾讯云TokenHub MiniMax-M3 / Hy-MT2-Pro双模型6月15日降价50%、DeepSeek-V3.2 7月16日下线倒计时形成"产品-价格-迁移"三线并发的B端商业化节奏。

DatabaseClaw商业化公告细节明确，体验版产品能力全部开放、月度积分额度固定（具体以产品控制台展示为准）、实例数量上限1个；企业版产品能力全部开放、按实际用量选择积分额度、不限实例数量、包年包月预付积分包计费。计费生效后，存量用户将默认归入体验版，体验版在14天服务缓冲期（6月19日0:00至7月2日23:59:59）内可继续免费使用全部能力；缓冲期结束后，体验版实例数量上限为1个，月度积分为固定额度、不支持跨月累积。本次调整不会自动升级至企业版，也不会产生自动扣费——如需使用企业版能力需由用户主动确认并完成付费。缓冲期结束后系统将依据实例创建时间（非最近使用时间）保留1个最新创建的实例，其余实例将自动进入隔离状态（实例服务不可用，保留7天，逾期销毁）。

DatabaseClaw的"对话即运维"核心定位源自腾讯云副总裁王义成4月在数据库+AI产品发布会提出的"数据库3.0时代"判断——数据库主要用户正从程序员变成Agent，传统DBA人力线性增长vs实例指数级爆发的剪刀差问题必须由AI Agent解决。DatabaseClaw内置腾讯云十万级真实DBA工单沉淀的排障经验，把顶尖DBA的SOP变成可复用的Skill；一个Agent覆盖关系型/NoSQL/SaaS等14款数据库产品、1600+ OpenAPI；通过权限隔离/AI行为护栏/架构安全/全链路审计四层安全护城河+ L1-L4细粒度操作分权实现生产级安全落地。L1（只读）、L2（低风险）、L3（中风险）、L4（高风险）四级操作分级确认机制，可有效降低AI助手被诱导执行危险操作的风险。

DatabaseClaw商业化的产业意义远超单点产品。它将腾讯云"工具-平台-数据库-AI"的全栈Agent能力下沉到客户数据库选型的核心决策点，与同期腾讯云TDSQL-C MySQL版备份商业化计费（6/18 14:57公告）、TCHouse-D海外弗吉尼亚ita5高性能型定价发布、云联网8.1计费调整形成"产品商业化+海外定价扩张+计费精细化"的三重商业化套拳。这一节奏与"5月TokenHub MiniMax-M3/Hy-MT2-Pro降价50%+6.15生效"形成"模型API降价+数据库服务提价"的双向价格调整信号——在云厂商竞争白热化阶段保持收入基本盘的同时，AI能力溢价定价权得到强化。对客户而言，腾讯云数据库产品线"按量付费+全栈Agent增值服务"模型已经基本定型，6.19是行业标志性定价节点。

6月18日18:57，火山引擎正式上线豆包实时语音模型3.0（Seeduplex）API服务并开启邀测。这是继豆包1.6系列大模型在文本/图像/视频多模态渗透后，火山引擎在实时语音交互领域的"端到端大模型"重磅升级。豆包实时语音模型3.0定位"原生全双工端到端语音大模型"——"全双工"意味着可同时进行听和说的双向实时通信，"端到端"意味着从语音输入直接到语音输出的全链路AI处理，无需传统ASR+LLM+TTS的串联拼接架构。这一升级让语音助手从"对讲机"变成了"真人助理"——能听、能说、能思考，还能在对话中完成复杂任务。

核心能力三大优势。精准遵循——模型对用户语音指令的理解准确率和意图识别精度大幅提升，在复杂指令/多轮对话/口音/语速变化场景下仍能保持高准确率；抗干扰——在环境噪声/多人会议/远场拾音/中英文混杂等真实场景下保持稳定识别能力；动态判停——模型能够智能判断说话人何时"说完了"，避免传统语音助手"抢话/插话/过长时间等待"的尴尬体验，"更懂何时听、何时说"。量化指标亮眼：判停延迟缩短约250毫秒，复杂场景抢话比例下降40%，用户主动打断时响应速度缩短约300毫秒，误回复率与误打断率大幅降低。官方演示场景：用户说"现在先别出声，聊到世界杯时再加入"，它就安静待命、不需要反复唤醒、当对话真的进入世界杯话题时自己开口接上。

工具调用能力是另一个被忽略的升级。此前语音助手能帮你设闹钟、查天气，这些都是预置功能；Seeduplex支持用户通过API自定义工具，可在实时语音对话中调用工具完成任务——预定日历、发送邮件、总结文档、发起查询，均可由一句话语音指令在对话流中自然完成，无需退出对话、无需切换到文本界面。火山引擎把这个叫"边听边说边办事"——从"懂你说"走到了"帮你做"。具体落地场景：汽车座舱里全车人聊天时导航AI只在需要提醒的时候开口，驾驶员随时打断改目的地不需要等它说完上一句话；智能硬件上老人说话不连贯、孩子边想边说AI耐心等；智能客服中用户说着说着换问题AI跟得上。邀测阶段面向企业级客户和开发者开放。

6月15日Kimi K2.7 Code专业编程大模型发布后，月之暗面公司6月15日又上线了Kimi K2.7 Code高速版，速度是常规版的6倍。常规编程场景下（取输入长度中位数）输出速度约180 Token/s，短上下文场景可达260 Token/s。K2.7 Code高速版和普通版是同一个模型，输出速度约为5-6倍，Kimi Code Plan用户可以加入"抢先体验计划"（kimi.com/code/beta）体验。高速版API定价为普通版的2倍——企业和开发者可通过Kimi API开放平台调用高速版模型，模型ID：kimi-k2.7-code-highspeed。Kimi方面提到在算力扩容之后会进一步扩大开放范围，预计从7月开始陆续开放给Allegretto及以上会员。

6倍速的高速版模型在Kimi Code Plan中的用量消耗是普通版模型的3倍，需要注意的是使用Kimi K2.7 Code系列模型须打开思考模式（Thinking）以发挥最佳性能。Kimi API和Kimi Code均默认开启思考，如果手动关闭思考模式，API会报错、Kimi Code会回退到K2.6模型。K2.7-Code采用1.1万亿参数MoE架构，每个token激活32B，256K上下文窗口，Modified MIT开源协议——Kimi Code Bench v2 62.0分（vs K2.6 50.9分）、Program Bench 53.6分、MLS Bench Lite 35.1分（与GPT-5.5的35.5几乎持平）、MCP Mark Verified 81.1分（比Claude Opus 4.8的76.4高）。

6月19日22:31新浪财经报道了一项由香港中文大学（深圳）、深圳鹏城湾区研究院、腾讯混元团队、北京科技大学、上海交通大学、南洋理工大学等多所机构联合开展的GameCraft-Bench评测研究——搭建了专门的测试平台考察当前最顶尖的AI编程助手到底能不能从零开始生成一款完整、可玩的游戏。成绩单：Claude Code搭配Opus-4.7"高配"模式以41.46%的总分拿下第一，GPT-5.5高配紧随其后得39.49%，Kimi-K2.6拿到30.65%，MiMo-V2.5-Pro得24.10%，GLM-5.1得18.29%，MiniMax-M2.7得10.95%，DeepSeek-V4-Pro只有2.15%——结果非常清醒：即便是表现最好的AI，100道题也只能拿到41分多一点。

研究发现的一致规律：所有AI在"核心机制"维度的得分都明显高于其他三个维度，以Opus-4.7为例核心机制得分55.34%、内容丰富度39.48%、画面功能性42.78%、美术呈现36.86%。Kimi-K2.6在140道题中共调用截图工具2998次，平均每道题截了21.41张图（Opus-4.7截了1952次、GPT-5.5只截了268次）——那些愿意频繁截图、用眼睛看游戏实际长什么样的AI，往往做出来的游戏质量更高。MiMo-V2.5-Pro的反面教材：5道题得0分但游戏全都成功启动了，原因是没提交操作录像导致评分系统无从打分。腾讯混元团队参与这项研究，意味着混元模型在AI编程游戏场景的实测基线已被建立——后续混元版本在该基准的提升将是腾讯云编程Agent能力的关键背书。
