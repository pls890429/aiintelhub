智谱GLM-5.2正式发布：1M上下文+MIT协议全场景商用免费，港股单日暴涨32.82%
2026-06-15 港交所公告 + 2026-06-13~15 全网发酵 · 36氪/极客公园/上海证券报/和讯网 | ✅ 已验证

6月15日，港股上市公司智谱（02513.HK）正式发布旗舰大模型GLM-5.2，将面向GLM Coding Plan全量订阅用户开放能力，覆盖Lite、Pro、Max及团队版所有订阅层级。与上一代GLM-5.1仅Pro与Max用户可使用完整能力不同，本次升级后即便是每月49元的Lite入门套餐用户也能直接调用具备百万Token上下文能力的完整版GLM-5.2。

GLM-5.2是智谱迄今能力最强的开源底座，核心突破是"真正可用的100万Token上下文窗口"。上下文从前代20万token跃升至100万token，社区实测评价显示该模型在500K上下文范围内仍能精确回溯关键信息，是当前上下文体验最接近"无限"的模型之一。架构层面延续MoE与DSA技术路线，对稀疏注意力机制进行大幅升级——这是支撑百万上下文真实可用的关键工程突破。编程能力方面，GLM-5.2在多项代码基准测试中跻身全球开源模型第一梯队，LLM Benchmark Code V3评测全球第三，仅次于GPT-5.5与Claude Opus 4.8；Flutter、Web、Game三大工程场景获A档评级。

最重磅的决策是，智谱宣布GLM-5.2将采用MIT协议开源权重，无任何地域限制，允许全球开发者自由下载、修改与商用部署。API接口将于下周上线，模型权重同步以MIT协议在Hugging Face与ModelScope平台开源。MIT协议是行业内最宽松的许可之一，允许免费下载、本地私有化部署、二次微调，并可直接用于商业产品，无版权与开源传染限制。智谱在声明中写道："前沿智能不应只属于少数人，也不应被少数规则随时收回。它应该开放、可用、可构建，并服务于每一位开发者。"

资本市场反应剧烈：6月15日智谱港股开盘一路走高，盘中最高涨幅触及47.68%，截至收盘涨32.91%报1458港元/股，单日成交额突破80亿港元，盘中振幅高达32.73%，总市值突破6496亿港元。这是公司自1月8日上市以来五个月累计涨幅约1154%后的又一次情绪爆发。资金面看，南向资金净买入港股超21亿港元，智谱作为AI大模型权重股是当日北水流入的关键支撑。财报数据进一步支撑估值：2025年智谱全年营收7.24亿元同比增长132%，MaaS API平台2025年末ARR达17亿元，过去一年提升60倍。

豆包"任务模式"全量上线：从"对话工具"到"执行助手"，智东西实测可自动点瑞幸咖啡
2026-06-15 22:28 智东西首发 + 2026-06-15 16:32 新眸深度长文 · 智东西/新眸/36氪 | ✅ 已验证

6月15日，字节跳动旗下豆包App全量上线"任务模式"，顶部模型切换栏从原来的"快速、专家"两档扩展为"快速、专家、任务"三档。任务模式的核心定义是"端到端完成任务"——AI拿到目标后先做规划，判断需要哪些步骤、调用哪些工具，然后按顺序自主执行，中间遇到问题还能自我修正。这标志着豆包从"你问一句我答一句"的对话模式，真正走向"你给目标我交付结果"的执行模式。

智东西记者第一时间实测发现，豆包任务模式可调用My Coffee Skill完成"自动点瑞幸咖啡"全流程：通过Skill机制安装瑞幸能力、配置MCP Token、搜索门店、生成订单、跟踪订单状态并返回取餐码——整个过程豆包没有弹出任何系统级权限申请窗口，既没有要求访问电脑、读取本地文件，也没有申请浏览器控制权限。这种"不获取系统权限、优先通过Skill机制调用能力"的设计，明显区别于目前主流桌面Agent的路线。任务模式目前公开的四项核心能力为零代码网页生成、一键PPT制作、Excel数据可视化、定时任务自动化。

支撑体验的是字节AI生态的完整闭环：底层大模型来自Seed系列（多模态理解、长链路推理、工具调用持续迭代）；算力和云服务由火山引擎保障（凭借字节内部业务的并池规模，支撑海量用户并发同时把推理成本控制在合理范围）；办公场景的产品经验来自飞书（文档、表格、PPT的处理逻辑多年迭代已摸透）。同一套底层能力在C端用豆包打用户心智，B端用火山引擎ArkClaw智能体平台做商业落地，硬件端与中兴合作AI手机、与车企合作智能座舱，形成了"模型+云+应用+硬件"的完整AI能力底座。

商业化层面，任务模式被纳入豆包专业版权益（标准版年费688元、专业版年费5088元），本质上是在验证"为效率付费"的C端商业模式。36氪报道指出，豆包将于Q3进一步结合电商功能更新完善付费场景并通过补贴为抖音商城引流，Q4进入运行期，所有动作都是为2027年及更长期的商业化回报做准备，2026年豆包将不会把付费用户渗透率作为考核指标。火山引擎副总裁杨立伟在AIVA发布会上的表态也印证了这一点——任务模式看起来是豆包一次功能更新，背后是字节AI战略的具象化落地。

⚡ 浙江影响：豆包任务模式+C端Skill机制+火山引擎ArkClaw B端平台形成完整产品矩阵，浙江电商运营、内容创作、企业办公自动化场景的Agent选型新增"豆包任务模式"对照选项；6.23-24字节Force大会预计将进一步升级任务模式付费场景，浙江B端ISV建议提前评估"豆包任务模式vs火山ArkClaw"组合接入路径

阿里云中标i茅台公有云项目：91分第一中标候选人全栈下浮12%，ACS Agent Sandbox降价今日12时正式生效
2026-06-15 16:19 每日经济新闻 + 2026-06-10 13:10 阿里云公告 · 每日经济新闻/新浪财经/科创板日报/财联社 | ✅ 已验证

6月15日，公开信息显示阿里云成功中标i茅台公有云项目，将为该平台提供计算、数据库与中间件、大数据、网络、大模型等全栈云资源。i茅台是茅台集团2022年推出的数字营销平台，截至2026年已拥有注册用户9643万人，2026年初调整产品矩阵后引发新一轮抢购热潮。招标于2026年5月19日由贵州爱茅台数字科技有限公司发布，6月15日发布中标结果。阿里云作为第一中标候选人，评分91分，中标价格为网络资源/其他配套资源/人力资源服务统一下浮12.00%、计算资源统一下浮12.00%、数据库与中间件资源统一下浮12.00%、大数据资源统一下浮12.00%、网络安全资源统一下浮12.00%。

联通数字科技为第二中标候选人（评分86.31分，下浮9.60%），中移系统集成为第三中标候选人（评分78.10分，下浮14.00%）。阿里云以91分最高评分和均衡的"全栈12%下浮"策略胜出，覆盖了茅台数字营销平台从基础设施到智能化运营的全部需求。此次合作旨在提升i茅台平台高并发承载能力与智能化运营水平，进一步巩固阿里云在头部消费品行业数字化转型市场的标杆地位。

同一天12时，阿里云容器计算服务ACS Agent Sandbox（default算力质量）降价正式生效。降价于6月10日公告生效，限定ACS Agent Sandbox（default算力质量）一项，ACS通用型（default、best-effort算力质量）、ACS性能型（default、best-effort算力质量）价格保持不变。ACS Agent Sandbox是阿里云面向AI Agent高并发场景推出的容器化算力产品，主打"开箱即用、弹性扩缩、按量付费"，直接对标腾讯云DatabaseClaw企业版的底层基础设施——这是阿里云在Agent容器赛道对腾讯云商业化公告的精准回应。

资本层面利好同步释放：6月12日高盛发布关于阿里巴巴-SW（09988.HK）的研报，维持"买入"评级，目标价180港元。高盛认为公司盈利下调周期见底、下半年盈利有望改善，AI+云业务具领导地位，AI产品将驱动外部云收入占比达50%，当前估值未充分反映其全栈AI及国际云潜力。这一系列"中标+降价+评级上调"组合拳，标志阿里云正在用基础设施降价+标杆案例+AI商业化故事三维打法，加速抢占AI Agent容器与企业级云市场。

腾讯云发布《关于DatabaseClaw正式商业化计费的公告》，宣布其数据库AI服务DatabaseClaw（数据库小龙虾）将于2026年6月19日0点（北京时间）正式开启商业化计费，并同步推出体验版（免费）与企业版（付费）两个版本。DatabaseClaw是腾讯云4月15日推出的数据库AI运维工具，专为DBA解决"凌晨被告警叫醒"的痛点：可三步操作三分钟完成部署，直接在内网连接数据库、数据不出网；支持一句话指令生成完整巡检报告、自动分析慢查询执行计划、按重要程度排序优化建议；可设置定时任务凌晨自动巡检、早上上班直接看结果。

商业化计费意味着DatabaseClaw从"产品验证期"正式进入"规模商业化期"，体验版/企业版分层设计精准卡位中小企业试用+大型企业付费的双轨需求。覆盖MySQL、Redis、MongoDB等主流数据库，支持自然语言生成SQL、自动优化查询、智能运维、异常自愈等能力。在安全合规层面，DatabaseClaw做到了"数据不出内网、权限严格管控、高危操作人工确认、全程留痕可审计"——这恰好是金融/政务/制造客户最关心的能力。

资本市场层面，腾讯控股6月15日回购110万股股份、耗资5.007亿港元；6月12日亦回购108.1万股、价值5.01亿港元，4月以来累计回购113亿港元。The Information独家报道显示，腾讯在通义大模型前首席研究员林俊旸创立的AI实验室首轮融资中投资2000万美元，实验室已筹集数亿美元。腾讯正在用"回购+投资+降价+商业化"组合拳，向市场传递"AI+云"双线发力的明确信号。

钛媒体6月13日深度分析指出，阿里AI战略正在经历"从底层逻辑到组织架构的全面重构"。2026年3月16日成立Alibaba Token Hub（ATH）事业群，由CEO吴泳铭亲自挂帅；4月8日成立集团技术委员会；6月8日合并通义大模型事业部和未来生活实验室成立Token Foundry事业部。架构调整后形成ATH事业群+Token Foundry事业部+AI未来研究院的三层架构，林俊旸出走、字节Seed顾全全离职与周靖人的首席科学家角色共同构成"科学家主导→商业主导"范式转变的标志性事件。腾讯在林俊旸新AI实验室首轮融资中投资2000万美元，进一步印证了阿里AI人才外溢与全行业争夺的现状。

同期间，高德正式发布全球首个3D原生城市世界模型ABot-Earth0.5，已建成全球覆盖面积最广的3D地图，遍及190多个国家和地区。用户输入一张卫星图像或一段文字描述，系统仅用10分钟就能在一块消费级GPU上生成公里级3D城市场景；输出为可编辑的3DGS格式素材，可直接导入Unity、Unreal Engine等主流引擎进行交互开发。3D制图成本仅为传统方式的百分之一，效率提升约一千倍。这是高德"空间智能"商业化的关键产品，落地后可服务自动驾驶仿真、智慧城市、游戏/影视内容生产、元宇宙等多个千亿级场景。

6月15日22:06，月之暗面Kimi宣布Kimi K2.7 Code模型高速版上线，现已向Kimi Code Beta计划成员、Kimi API开发者、Kimi Business用户开放。高速版与Kimi K2.7 Code是相同模型，输出速度约为普通版的5-6倍，常规编程场景下（取输入长度中位数）输出速度约180 Tokens/s，短上下文场景可达260 Tokens/s。这是月之暗面"高频编程场景"产品策略的进一步落地——通过Speed-Tier产品形态满足不同场景的差异化需求。

价格方面，高速版为Kimi K2.7 Code的两倍：1M tokens的标准输入和输出价格分别为13元和54元；命中缓存的输入价格为2.6元。普通版价格与K2.6完全一致，标准输入6.5元/百万token、标准输出27元/百万token、缓存命中输入1.3元/百万token。Hugging Face Model Card显示K2.7 Code核心规格：MoE 1T总参/32B激活、256K上下文、视觉编码MoonViT（400M）、开源协议Modified MIT、原生INT4量化。

内外部基准评估显示，Kimi K2.7 Code相对K2.6显著提升：Kimi Code Bench v2 +21.8%、Program-Bench +11%、MLS Bench Lite +31.5%、Kimi Claw 24/7/MCP Atlas/MCP Mark Verified均约+10%。官方强调在长程任务中大幅改善"过度思考"，平均token消耗减少约30%——主要来自thinking-token的下降，这对Claude Code、OpenClaw等长会话Agent的直接意义是：同样任务更省额度、更少等待。官方口径明确："非编程任务请继续用K2.6"——这种主动划边界、集中力量做编程的做法相当克制。

Fable 5/Mythos 5是Anthropic迄今最强的旗舰模型，定价较Opus 4.8翻倍（每百万输入/输出 token 10/50美元），输出价格为Opus 4.8的两倍、GPT-5.5的1.7倍，性能在几乎所有AI基准测评中全球领先、视觉处理/软件工程能力显著提升。Mythos 5解除了安全护栏，目前仅向Project Glasswing伙伴和少量生物研究者开放。突然停服直接冲击大量依赖海外模型的开发者和企业工作流，社区内关于替代方案的讨论热度快速攀升。

就在Anthropic停服发酵的次日，6月13日智谱宣布GLM-5.2面向Coding Plan全量用户开放——这是国产大模型在Anthropic封禁窗口的精准"补位"。36氪指出，Anthropic事件暴露出"能力之外，模型是否能够持续、稳定地获得访问权限"这一此前容易被忽视的问题。当AI逐渐从聊天工具变成软件开发、企业运营乃至生产流程中的基础设施，模型的稳定性、可持续性和可控性开始成为与模型能力同样重要的指标。智谱MIT开源+智谱调入港股通+小米MiMo永久降价+DeepSeek V4-Pro当前促销价转为正式价（5月底永久下调至2.5折），国产阵营正形成集体"补位"效应。

6月12日，金山云官网发布价格调整公告，因全球AI算力需求攀升、硬件成本上涨，为保障服务质量及算力资源持续供给，经审慎评估，金山云7月12日起将对部分产品价格进行调整：AI算力相关产品服务价格上调约15%-50%，文件存储相关产品服务价格上调约30%-50%。这是继阿里云、百度智能云、腾讯云之后，行业性调价潮的进一步延续，AI算力从"内卷定价"向"供需定价"的拐点正在形成。

云厂商集体调价的根本原因是算力供给侧的成本压力。Epoch AI测算数据显示：全球顶级Blackwell芯片算力年均增速仅3.4倍，但全球AI Token需求年均增速高达10倍，算力供给与需求差距持续拉大。硬件端，全球95%以上的高端内存产能被三星、SK海力士、美光三家企业垄断，HBM高端内存价格涨幅超50%，普通DDR5服务器内存半年暴涨300%，单条256G内存售价突破4万元。一台8卡英伟达B300服务器报价从不足400万元飙升至700万元，现货依旧供不应求。

算力成本上涨已传导至下游应用。微软自2026年6月1日起对GitHub Copilot全面重构定价体系，切换为精准的按Token计费模式，不同模型的单Token成本差距最高达60倍。有用户测算，原本每月39美元的Copilot Pro+套餐在新计费规则下单月账单或将暴涨至800美元以上。Uber向5000名工程师开放Claude Code编码助手后，工具月活使用率飙升至85%-95%、人均每月API消耗500-2000美元，Uber管理层紧急将员工单人每月AI工具消费上限严控为1500美元。国产大模型2025-2026年的"价格战"部分原因正是2025年H1尚未触及算力瓶颈，2026年下半年开始的"涨价+稳价"将成为新主线。
