DeepSeek
DeepSeek V4峰谷定价8月17日零点正式生效：V4 Pro高峰输出27元、缓存命中涨12倍，错峰调用可省一半
来源：DeepSeek官网公告 / 中国证券报 / 华尔街见闻 · 2026-08-17

8月13日晚预告的DeepSeek V4系列调价于今日（8月17日）零点正式落地。新价格表显示，V4 Pro高峰时段（工作日9:00-12:00、14:00-18:00）输出价由6元/百万tokens上调至27元，涨幅350%；未命中输入由3元涨至9元，涨幅200%；缓存命中输入由0.025元上调至0.30元，涨幅高达1100%，是本轮调价中冲击最大的一项。V4 Flash同步引入峰谷计费，高峰输出由2元涨至9元。空闲时段（含夜间、凌晨、周末）统一按高峰价的50%计费。

这是国内大模型行业首次将电力行业"分时电价"逻辑搬到API定价上，官方解释为"鼓励用户根据实际使用情况调整任务时间，更合理调配资源"。据摩根士丹利8月9日研报，2026年Q2中国大模型API均价输入4.9元、输出21.9元，同比分别上涨48%和80%；OpenRouter周榜显示V4 Flash以7.22万亿Token周调用量居全球第一，8月1日单日处理Token总量达8万亿，一度因访问量空前导致容量不足。

⚡ 对浙江客户影响：白天高峰跑Agent/代码生成的SaaS和企业业务账单将明显抬升；离线批处理、夜间训练、向量化任务建议全面错峰至闲时。多模型兜底架构成为刚需，单一依赖DeepSeek API的风险敞口已经显性化。
阿里云
阿里云百炼MU模型单元8月16日起调价2%-7%：预付费算力包首次跟进，"模型单元"模式成本曲线抬升
来源：阿里云官网公告 / GMT8 Press · 2026-08-16

阿里云8月16日发布公告，对大模型服务平台"百炼"部分MU（Model Unit，模型单元）的服务价格进行适度调整，涨幅区间为2%-7%。公告给出的调价理由与3月18日AI算力、存储调价一脉相承——"为继续保障底层硬件稳定供应、提升平台运维服务质量、响应市场算力成本变化"。

MU是百炼平台面向企业客户推出的预付费算力单元，主要用于包年包月方式锁定Qwen系列及第三方模型的调用额度，区别于按量计费的Token API。此次MU调价意味着涨价压力从按量后付费市场进一步传导至预付费/包年合约市场，企业级客户的长期算力预算面临重估。此前阿里云已于3月上调AI算力和存储服务5%-34%，此次2%-7%的幅度相对温和，但方向明确——算力供给侧的涨价周期仍在延续。

⚡ 对浙江客户影响：已签百炼MU包年合约的客户需关注续约报价；新签客户建议锁定更长周期并叠加节省计划（最高5.3折）对冲后续涨价。可借此机会推动客户做"百炼+华为云+火山"多供应商架构，避免单点议价权流失。
火山引擎
火山引擎Seedance 2.5 API正式上线：原生30秒视频直出、支持50个全模态参考，多模态生成进入"长叙事"阶段
来源：火山引擎 / AIBase / 每日AI知识库 · 2026-08-16

火山引擎8月16日正式上线Seedance 2.5 API服务。相比2.0版本，新模型在指令遵循、长叙事连贯性、真人质感及声画同步四个维度全面升级，原生支持单段30秒视频直出（2.0上限为15秒），最多可同时输入50个全模态参考素材（文本、图像、音频、视频混合），并支持局部可控编辑与精准视频剪辑，兼容中文、英文等十余种语言。

Seedance 2.5可稳定承接专业3D资产创作，输入近10万面白模即可生成稳定渲染视频，已在LibTV、奇想AI、TapNow等平台同步上线。模型同时上架即梦AI和豆包Pro面向C端创作者，API通过火山方舟对外提供。这是继7月底豆包1.6系列、图像编辑3.0、同声传译2.0之后，火山引擎在多模态生成栈上的又一次关键补齐，视频生成长度、参考素材数量均刷新国产模型纪录。

⚡ 对浙江客户影响：浙江电商、影视、广告、教育密集产业带可直接接入30秒商品主图视频/短剧/课程片自动化生产；制造业客户可用于3D白模→产品演示视频的渲染管线。建议重点跟进义乌小商品、杭州直播电商、横店影视、宁波外贸四个场景的POC。
🟡 厂商官方动态
腾讯云
腾讯云Agent Bucket正式发布：为亿级Agent提供独立云空间，统一存储素材/报告/图像/代码等工作产物
来源：腾讯云 / GMT8 Press · 2026-08-17

腾讯云8月17日正式发布Agent Bucket（智能体存储桶）。这款产品被定位为"给每个Agent一个独立的云空间"，可统一存储用户上传的素材，以及Agent在执行任务过程中生成的报告、图像、代码等各类文件和工作产物，面向亿级Agent规模设计。

Agent Bucket并非传统对象存储的简单换皮，而是针对Agent工作流做了读取优化——支持流式读取、高并发小文件吞吐、与ADP（智能体开发平台）和WorkBuddy深度集成。灵生科技训练世界模型时曾遇到瓶颈：大量碎片化视频和小文件无法及时送入训练设备，再贵的GPU也只能空转；接入Agent Bucket和流式读取后，问题从"能不能存下数据"转变为"怎么把GPU真正喂饱"。这是腾讯云在Agent基础设施层（存储/传输/计算/弱网保障）卡位的关键一环，与WorkBuddy、CodeBuddy、ADP、SkillHub形成完整闭环。

火山引擎中国移动
火山引擎×中国移动智算中心全国最大机密Token工厂落地呼和浩特：万卡国产集群+全流程加密推理
来源：呼和浩特片区 / 今日头条 · 2026-08-17

中国（内蒙古）自由贸易试验区呼和浩特片区和林格尔新区区块披露，由中国移动智算中心与火山引擎联合打造的"移动引擎机密模型服务"已正式落地运行。依托万卡级国产智算集群，该项目建成了目前全国规模最大的机密Token工厂，核心特征是推理过程加密、数据传输加密、全链路留痕可追溯。

和林格尔新区正在梯次推进十万卡级、二十万卡级智算集群建设，并已规划百万卡级算力蓝图。此次合作是火山引擎在"算力+安全+合规"三位一体方向的标杆案例，面向金融、政务、央国企等对数据不出域、推理可审计有强需求的客群。区别于通用公有云MaaS，机密Token工厂把国产算力、机密计算、模型服务打包成可信算力供给，对浙江区域的金融、政务、军工配套客户具备直接参考价值。

阿里云浙江属地
阿里云入围"联通浙江产业互联网浙江省大模型接口服务采购"中选候选人：省级运营商大模型集采再下一城
来源：企查查 / 联通招标公示 · 2026-08-14公示 08-16更新

据企查查8月16日更新信息，阿里云在"2026-2027年联通（浙江）产业互联网有限公司浙江省大模型接口服务采购项目"中成为中选候选人。这是浙江省级运营商层面对大模型API服务的集中采购，覆盖全省联通体系的大模型接口需求，是运营商作为MaaS分销渠道的典型信号。

该项目对浙江区域云计算市场格局有直接影响：联通浙江产业互联网是浙江政企业务上云的关键通道，阿里云通过此次入围可借运营商渠道触达大量地市政务、国企、中小企业客户。叠加8月14日阿里云中标北京公交集团2026-2029年公有云服务项目（342万元）、8月13日中石油智能化地震作业系统公有云项目，阿里云在政企和运营商赛道持续拿单。浙江团队需重点关注华为云在联通浙江体系的存量卡位和反击窗口。

🟢 行业动态
行业人才
前阿里千问大模型技术负责人林俊旸离职创办语用科技：大厂基座模型核心人才出走潮延续
来源：第一财经 / 36氪 / 财中社 · 2026-08-16

据第一财经、财中社等多家媒体8月16日报道，前阿里巴巴千问大模型技术负责人林俊旸已离职创业，新公司名为"语用科技"。林俊旸是Qwen系列基座模型的核心技术负责人之一，其出走被视为2026年大厂AI核心人才流动的标志性事件。此前已有多位大模型核心技术人员从阿里、字节、腾讯等公司离职创业或加入竞品。

林俊旸的"决裂与妥协"折射出大厂内部在模型路线（开源vs闭源、蒸馏vs自研、基座vs应用）上的深层张力。结合字节张一鸣8月初明确拒绝蒸馏、阿里Qwen3.8系列密集开源、智谱选择"不换基座、靠后训练"的差异化路线，国内大模型第一梯队正在从"参数军备竞赛"转向"路线选择竞赛"。对云厂商而言，基座模型人才的流动会直接影响模型迭代节奏和生态稳定性，需持续跟踪。

政策算力
北京下半年布局Token工厂、力争新增智能算力5万P：地方政府加速入场算力调度与Token经济
来源：北京市经信局 / e公司 · 2026-08-15

北京市经信局披露，下半年将制定Token经济发展政策，围绕Token生产、分发、应用等关键环节，布局建设Token工厂、Token分发平台，重点推动工业、教育、文旅等领域创新应用；同时力争新增智能算力5万P。这是继上海、深圳、合肥之后，又一直辖市层面明确Token经济政策框架。

Token工厂的本质是地方政府牵头的算力调度与模型服务集采平台——由政府或国资平台统一采购国产算力、接入主流大模型、以Token为计量单位向本地企业分销，本质上是"算力券"的升级形态。对云厂商而言，Token工厂既是政企订单入口，也是渠道被截流的风险点。浙江目前尚未出台省级Token工厂政策，杭州、宁波等地市已有类似布局，建议华为云浙江团队提前对接省经信厅、省算力中心，争取在政策设计阶段嵌入华为云算力底座。
