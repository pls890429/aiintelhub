阿里云通义万相Wan3.0视频生成模型公测：单次30秒直出对标Seedance 2.5，首次支持文档直转视频"PPT扔进去成片吐出来"
2026-08-06 · 阿里云公众号/IT之家/网易/光子星球实测 | ✅ 已验证

8月6日晚，阿里云宣布全新一代视频生成模型Wan3.0正式开启公测。这是通义万相模型家族从1.0到3.0迭代的第8个版本，核心突破集中在四个维度：生成时长、万能创作、全能参考与真实感还原。最引人注目的是单次生成视频时长从上一代的5-10秒跃升至30秒，追平字节Seedance 2.5保持的行业最高单段档位，从"生成一个镜头"走向"讲述一段完整故事"，连续运镜、一镜到底等复杂镜头语言得以充分表达。

Wan3.0最颠覆性的差异化能力是"万物皆可生视频"。在文本、图片、音频、视频四种基础模态之外，Wan3.0首次支持doc、xls、ppt、pdf、txt、key、pages、numbers以及md等文档格式输入，用户上传一个产品PPT配上提示词即可直接生成形象片。这意味着大量办公素材可以直接转化为视频，将"文案—分镜—拍摄—剪辑"四个环节一次性压缩进一个动作。模型还支持智能时长推荐、视频延长功能，以及精准的视频局部编辑能力，在全能参考任务中可保持角色五官、服饰、道具Logo、场景空间关系等多维度一致性。

价格方面，Wan3.0走性价比路线，480P/720P/1080P的API价格分别为0.3/0.6/1.2元每秒，30秒1080P成片约36元，720P约18元。目前已通过阿里云百炼、万镜一刻、万相官网、千问创作PC端开启公测，千问APP灰度开放，API接口将于近期全量开放。媒体实测显示，Wan3.0在30秒长叙事、中文文字渲染、文档转视频链路上表现突出，但在精细道具锁定和多视角物理同步方面仍有提升空间，官方也承认"在声音质感与文字准确度方面仍有进步空间"。这一发布标志着阿里在AI视频生成赛道上直接对标字节Seedance 2.5，两家在30秒单段时长上形成正面竞争格局。

⚡ 浙江影响：Wan3.0的文档直转视频能力为浙江制造企业的产品演示、培训课件、品牌宣传等场景提供了"PPT变视频"的工业化工具，30秒1080P成片36元的成本远低于传统外包制作，浙江电商企业可用720P（18元/条）批量生成商品短视频，建议先用公测跑一遍实际素材验证角色一致性和音画质量再进入生产流程

阿里推出国内首个AI语音生产力平台CosyVoice Studio：Qwen-Audio斩获ASR/RealTime/TTS三项全球第一，覆盖"听-创-聊"全链路语音能力
2026-08-07 · IT之家/观察者网/CNMO科技 | ✅ 已验证

8月7日，阿里巴巴正式推出国内首个一站式AI语音生产力平台CosyVoice Studio，基于自研Qwen-Audio语音大模型家族打造。Qwen-Audio在全球第三方评测平台Artificial Analysis 7月28日的榜单中表现亮眼：Qwen-Audio-3.0-Realtime综合指数（Speech to Speech Index）达84.1%摘得全球桂冠，语音推理、智能体表现和对话动态三个子项也均为世界第一，语音识别（ASR）、实时交互（RealTime）和语音合成（TTS）三个赛道均斩获全球第一。

CosyVoice Studio将语音AI拆解为三大核心功能模块。CosyFlow是面向个人效率场景的语音记录工具，在语音转文字基础上叠加语义理解和文本生成能力，可自动过滤口语填充词、将零散口述整理为正式邮件或工作汇报，支持根据声纹区分不同发言人并自动生成结构化章节和智能摘要，单次最长支持6小时连续录音。CosyCreative是音频内容创作工具，内置上千种音色并支持声音复刻，用户上传文档或网页链接即可生成对话播客或多角色有声书，将传统按天计算的内容制作周期压缩到分钟级。CosyAgent面向企业服务，支持通过自然语言快速创建具备企业知识、工具调用和实时语音交互能力的智能体，兼容prompt与workflow配置，面向智能客服、电话营销等场景。

即日起用户可在iOS、Android、Mac和Windows应用商店搜索"CosyVoice"下载，不限量免费体验。CosyAgent和CosyCreative目前以白名单邀请制面向企业用户测试，近期将全面开放。这一发布标志着国内AI语音赛道从单点工具竞争走向平台级能力竞争，阿里试图走出一条从模型能力到产品生态的语音商业化路径——将千问、钉钉、高德、淘天等真实业务场景的长期打磨经验，转化为可对外输出的语音生产力基建。

⚡ 浙江影响：CosyVoice Studio的三模块设计为浙江企业提供了从语音记录到内容创作到智能客服的全链路方案，CosyFlow的会议纪要自动生成和CosyAgent的企业知识库语音Agent可直接应用于浙江制造企业的客户服务和内部协作场景，建议钉钉用户优先评估CosyAgent与现有工作流的集成可行性

腾讯云Agent Memory 2.0.0大版本上线Team Memory：MIT开源团队级Agent记忆共享框架，四层蒸馏+ACL权限治理登GitHub趋势榜第一
2026-08-06 · 腾讯云官方/IT之家/MarkTechPost/VentureBeat | ✅ 已验证

8月6日，腾讯云宣布Agent Memory 2.0.0大版本正式上线，核心升级是全新推出Team Memory功能，将长期记忆能力从个人Agent扩展到团队协作场景。团队与Agent协作过程中产生的代码知识、项目文档、历史对话和工作方法，都可以沉淀为团队长期记忆，在不同Agent之间共享，再根据Agent角色和具体任务按需装配。项目MIT开源、自托管，三条Docker镜像一键部署，已登GitHub TypeScript趋势榜第一。

系统将工作成果转化为四类可复用记忆资产：Chat Memory保留偏好、事实、决策和交互历史，通过L0到L3四层蒸馏（L0原始对话→L1事实原子→L2场景知识块→L3长期画像），用BM25+向量检索+RRF在预算限制下召回；Skill将已完成任务提炼为带版本、资源文件、触发边界和验证规则的可复用流程；Wiki将文档整理为结构化页面和链接图谱；CodeGraph索引代码仓库的文件、符号、调用关系和影响路径。这套设计让新Agent加入团队时不需要重读数百轮历史对话，而是拿到与自身角色匹配的一组"装备"即可上手。

Team Memory的真正差异化在于ACL治理层——可见性分为private（仅所有者可读，团队管理员也不可读）、team、restricted和agent定向装备四档，新创建的Chat Memory和Skill默认私有，共享是显式行为。腾讯自测PersonaMem准确率从48%提升至76%，相对提升59%。系统兼容Anthropic和OpenAI两种协议，官方SDK覆盖TypeScript和Python，已支持OpenClaw、Hermes、Claude Code、CodeBuddy等集成。2.0.0版本还新增了Skill强制归档、CodeGraph定时同步、系统管理员资产管理、中英文面板切换和Cost Guard（为特定Agent分配更便宜的模型）等功能。

⚡ 浙江影响：腾讯云Agent Memory 2.0的MIT开源和自托管特性为浙江企业提供了不依赖外部API的团队级Agent记忆基础设施，Coding Agent团队可评估其Chat Memory+Skill+Wiki+CodeGraph四件套在代码审查、故障排查、发布流程等场景的复用价值，ACL权限治理满足企业数据安全要求

阿里云百炼平台部分MU模型单元调价2%-7%：响应算力市场成本变化，保障底层硬件稳定供给
2026-08-08 · 阿里云公告/gmteight | ✅ 已验证

8月8日，阿里云发布官方公告，宣布对大模型服务平台"百炼"上的部分MU（模型单元）模型服务进行适度价格调整，涨幅范围为2%至7%。阿里云在公告中表示，调价目的是"为持续保障底层硬件的稳定供给、提升平台运维服务质量，并响应市场算力成本变化"。这是继上周DeepSeek预告大幅涨价、腾讯云核心产品涨幅超400%、阿里云算力卡服务涨34%之后，又一云厂商在算力成本传导上的实际动作。

此次调价针对的是百炼平台的MU模型单元——即底层算力计量单元，而非具体的模型API调用价格。2%-7%的涨幅相对温和，反映出阿里云在算力成本上升压力下采取的是渐进式调价策略，而非一步到位的大幅提价。这一策略与阿里云近期在模型API侧的降价形成对比：同期阿里云对Qwen-VL系列视觉理解模型进行了超过80%的降价，通过基础设施优化和规模效应降低推理成本，同时通过弹性AI算力调度系统和百炼分布式推理加速引擎进一步压缩成本。

从行业趋势看，算力成本的全链路传导已从硬件端（HBM内存暴涨50%、CoWoS封装排到年底）逐级传导至云厂商基础设施（MU涨价）和大模型API（DeepSeek预告大幅涨价），企业需要建立Token消耗的精细化管理体系。阿里云此次温和调价加上KV Cache新计费模式的推出，显示其在"算力成本上涨"和"模型使用门槛降低"之间寻求平衡——底层算力适度涨价以覆盖成本，模型API持续降价以扩大生态。

⚡ 浙江影响：阿里云百炼MU模型单元2%-7%的温和涨幅对浙江企业的直接影响有限，但需关注这是否是持续调价的开始，建议盘点百炼平台上的MU使用量和月度支出，评估KV Cache新计费模式能否抵消涨价影响，同时关注模型API侧的降价红利是否已覆盖到企业实际使用的模型

从估值轨迹看，月之暗面在2026年几乎以月为单位跳涨。2025年12月C轮投后估值约43亿美元，到2026年8月冲刺500亿美元，七个月时间上涨超8倍。若按单轮稀释10%测算，本轮募资规模将接近60亿美元。34岁的创始人杨植麟持股比例对应身家已突破1100亿元。月之暗面此前已否认"本月内向港交所提交IPO申请"的传闻，但5月已向股东通知VIE拆除、启动上市筹备，并与中金公司、高盛等投行接触。参考同行节奏，智谱已于2026年1月登陆港股，MiniMax也已完成上市，港交所18C章通道为AI公司提供了清晰的上市路径。
